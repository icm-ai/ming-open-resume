# Ming Open Resume

A repository for a React and TypeScript résumé-builder application.

## Project provenance

The current `package.json` identifies the application as **dnd-resume** and credits **Arman Tang** with the upstream repository [Arman19941113/dnd-resume](https://github.com/Arman19941113/dnd-resume). This repository should therefore **not** be presented as a verified original implementation without documenting which changes, if any, were authored here.

## Tech stack

The dependency manifest includes React 19, TypeScript, Vite, Tailwind CSS, dnd-kit, TipTap, and Zustand.

## Local development

Install dependencies with the package manager associated with the repository's lockfile, then run:

```bash
npm run dev
```

To build and check the project:

```bash
npm run build
npm run lint
```

The scripts above are taken from `package.json`. They have not been executed or validated as part of this documentation update.
